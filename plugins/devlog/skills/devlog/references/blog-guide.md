# 블로그에 올리는 방법

이 스킬이 만드는 파일은 세 가지다.

- `devlog/YYMMDD.md` — 정본(마크다운)
- `devlog/YYMMDD.html` — 붙여넣기용. 이미지가 파일 안에 들어 있다.
- `devlog/assets/YYMMDD/` — 일지에 쓴 이미지 원본과 영상 썸네일

어느 블로그든 공통인 사실이 하나 있다. **내 컴퓨터에 있는 파일 경로로 적은 이미지는 블로그가 불러오지 못한다.**
그래서 이미지는 (1) HTML에 파일째 넣어 붙여넣거나 (2) 에디터에서 직접 올려야 한다.
캡션의 "그림 N"은 (2)를 할 때 사진이 들어갈 위치를 알려 준다.

## 확인 수준을 먼저 밝힌다

| 블로그 | 확인 수준 |
|---|---|
| 네이버 | 공식 자료를 찾지 못했다. 한 개발자의 사례(비공식)만 참고했다. **직접 시험하지 못했다.** |
| 티스토리·벨로그·노션·GitHub | 일반적으로 알려진 동작이다. 이 스킬을 만들면서 직접 시험하지 못했다. 화면 구성은 바뀔 수 있다. |

처음 한 번은 **비공개(또는 임시저장) 글로 시험**해서 이미지와 코드가 어떻게 보이는지 확인하고,
어긋나는 점을 사용자에게 알려 달라고 한다. 그 결과로 이 문서를 고친다.

## 네이버 블로그

마크다운이 자동 변환된다는 공식 자료를 찾지 못했으므로 `.html` 방식을 쓴다.

1. `YYMMDD.html`을 브라우저(크롬 권장)로 연다.
2. 맨 위의 **[본문 복사]** 버튼을 누른다.
3. 네이버 블로그 글쓰기 화면의 본문에 Ctrl+V 한다.

시험 결과에 따른 대응:

- 이미지가 안 붙으면: 텍스트만 붙인 뒤, `assets/YYMMDD/`의 사진을 글의 "그림 N" 순서대로 에디터에서 올린다.
  (참고한 사례에서는 `file://` 주소의 이미지를 네이버가 가져오지 못했다고 한다. HTML 안에 넣은 이미지는 시험이 필요하다.)
- 코드 서식이 깨지면: 에디터에 코드 입력 기능이 있으면 그걸 쓰고, 없으면 코드 부분만 `.md`에서 복사해 붙인다.
- 영상은 에디터의 동영상 올리기로 직접 올린다. 일지에는 썸네일만 들어 있다.

## 티스토리

글쓰기 화면에서 편집 모드를 바꿀 수 있다(기본 / 마크다운 / HTML).

- 마크다운 모드: `.md` 내용을 붙여넣고, `![...](assets/...)` 줄은 에디터의 이미지 올리기로 다시 넣는다.
- HTML 모드: `.html`의 `<body>` 안 `<div id="post">` 부분을 붙여넣는다. 이미지가 파일째 들어 있어 용량이 크면 거부될 수 있으니, 그럴 땐 마크다운 모드를 쓴다.

## 벨로그

마크다운 에디터다. `.md` 내용을 붙여넣고, 이미지 줄은 사진 파일을 에디터로 끌어다 놓아 올린 뒤 주소로 바꾼다.

## 노션

`.md` 텍스트를 붙여넣으면 제목·목록·코드가 블록으로 바뀐다. 이미지는 따로 올린다.

## GitHub (README, Jekyll, GitHub Pages)

`.md`와 `assets/` 폴더를 같이 올리면 상대경로 그대로 동작한다.
단, 수업 저장소의 `.gitignore`가 `*.jpg`, `*.png`, `*.mp4` 등을 제외하고 있으면 이미지가 올라가지 않는다.
일지용 폴더만 예외로 두려면 `.gitignore`에 `!devlog/assets/**`를 추가한다.

## 새 블로그를 쓰고 싶을 때

블로그가 (1) 마크다운을 받는지 (2) HTML 붙여넣기를 받는지 (3) 이미지를 어떻게 올리는지 세 가지만 확인하면 된다.
마크다운을 받으면 `.md`, 못 받으면 `.html`을 쓰고 이미지는 위 공통 사실대로 처리한다.
